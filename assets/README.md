# Artes para a apresentação

Para mostrar o **cartaz original desenvolvido no Figma** no slide 6, envie seu PNG para esta pasta com o nome exato:

`cartaz-free-las.png`

O HTML usa automaticamente a imagem, se ela existir. Enquanto isso, mostra uma **reconstrução tipográfica ilustrativa** para manter o slide funcional.

Não envie fotos de participantes ou logotipos que não tenham autorização de publicação. As assinaturas institucionais continuam pendentes de validação com o LA-BORA!gov.
